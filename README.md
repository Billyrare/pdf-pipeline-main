# PDF Pipeline

Проект предназначен для автоматического скачивания документов по списку ID и последующей конвертации файлов с помощью Node.js + ИИ.

## Основные компоненты

- `runner.js` — главный Node-скрипт, который последовательно проходит по файлам `docs/ids/ids1.txt`…`ids36.txt`.
- `package.json` — описывает зависимости и команды:
  - `yarn cv` — запускает конвертацию скачанных файлов в JSON через `src/convert-pdf/index.js`
- `docs/files` — папка, куда выгружаются файлы с `uzpharm`.
- `docs/ids` — папка со списками ID документов для загрузки. Файлов 36, чтобы избежать спама и блокировок.
- `docs/new1test` — тестовый документ/папка, используемая для отладки.
- `docs/splitted` — кейс с одной карточкой, где инструкция по применению разбита на два файла. Система умеет собирать такие документы в один JSON.
- `progress.json` — файл, содержащий последний обработанный файл, чтобы при повторном запуске не проходить по всем файлам заново.
- `rmtDownloadScript/` — Python-сценарий для выгрузки документов из RMT через UI и гугл-таблицу.

## Требования

### Node.js + Yarn

Для работы проекта необходимо установить:

- Node.js (рекомендуется версия 18+)
- Yarn


### Python

Для запуска Python-скрипта требуется установить зависимости из `requirements.txt`.
```bash
cd rmtDownloadScript/
pip install -r requirements.txt
```

## Переменные окружения

Проект использует файл `.env` для следующих параметров:

- `COOKIE` — cookies от `uzpharm`, которые нужны для доступа и скачивания файлов.
- `ANTHROPIC_API_KEY` — токен для Anthropic, используемый при конвертации через ИИ.
- `DB_URL` — строка подключения к PostgreSQL, где сохраняются результаты конвертации.


После `yarn cv` конвертированный JSON сохраняется в базу PostgreSQL. В таблице сохраняется связка `id документа` + `json`.

## Установка

1. Нужно установить Node.js и Yarn.
2. В корне проекта запустите:

```bash
yarn install
```

3. Убедитесь, что файл `rmtDownloadScript/dulcet-field-497411-p8-c52c98ec130d.json` доступен для Python-скрипта.

## Запуск загрузки UzPharm

В этом проекте загрузка документов выполняется по файлам ID из `docs/ids`.

```bash
node runner.js
```

`runner.js`:

- читает все файлы `docs/ids/ids*.txt`
- смотрит `progress.json` и продолжает с последнего необработанного файла
- вызывает `yarn dw` для каждого файла
- сохраняет прогресс в `progress.json`

Если нужно прервать процесс, нажмите `Ctrl+C`. При повторном запуске `runner.js` продолжит с последнего успешно обработанного файла.

## Конвертация файлов

После скачивания файлов выполните:

```bash
yarn cv
```

Это запустит `src/convert-pdf/index.js` и преобразует данные в нужный JSON-формат.

## Ручная выгрузка через RMT

Папка `rmtDownloadScript/` содержит Python-скрипт для выгрузки документов из RMT через UI и Google Sheets.

- `download.py` — основной скрипт.
- `dulcet-field-497411-p8-c52c98ec130d.json` — credentials Google Sheets.
- `log.txt` — лог выполнения. Через него можно найти последнюю обработанную строку и продолжить загрузку.

### Как работает `download.py`

- использует Google Sheets API для получения данных по ключу `SPREADSHEET_ID`
- выгружает документы в папку `asl_belgisi_documents`
- внутри создаётся папка с `product_id`
- в каждой папке сохраняются документы из полей таблицы
- если файл уже скачан, он пропускается
- при `429` повторяет попытку с увеличенным таймаутом
- параметр `START_ROW` позволяет начать скачивание с нужной строки таблицы

## Структура папок

- `docs/files` — результаты выгрузки UzPharm
- `docs/ids` — входные ID для загрузки
- `docs/new1test` — тестовый файл/папка
- `docs/splitted` — кейс с разбитыми файлами
- `rmtDownloadScript/` — Python-скрипт для Google Sheets / RMT
- `asl_belgisi_documents/` — итоговая папка загрузки из `download.py`

## Полезные советы

- Для возобновления загрузки `rmtDownloadScript/download.py` измените `START_ROW`.
- `log.txt` помогает найти последний загруженный продукт.
- `progress.json` нужен только для `runner.js` и `docs/ids`-потока.
- При работе с `uzpharm` используйте файлы `docs/ids/ids1.txt`…`ids36.txt`, чтобы снизить риск блокировки.
- `config.js` - файл в основном с промтом, можно корректировать если нужно.

## Статус

Проект объединяет два потока:

1. Node.js-поток для загрузки/конвертации данных из `docs/ids` и `uzpharm`.
2. Python-поток для выгрузки документов из RMT через Google Sheets.
